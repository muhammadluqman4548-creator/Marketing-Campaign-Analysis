# Marketing Campaign Analysis Dashboard

## Project Overview

This project presents an interactive Power BI dashboard developed to analyze digital marketing campaign performance. The dashboard helps evaluate campaign effectiveness, compare platform performance, identify customer segments, and support data-driven business decisions.

## Project Objective

The objective of this project is to analyze marketing campaign performance by identifying the best-performing campaign objectives, evaluating platform performance, understanding customer segments, and providing actionable business recommendations.

**Dataset:** Tech Advertising Campaigns Dataset

The dataset includes information such as:

- Campaign ID
- Campaign Objective
- Platform
- Quarter
- Industry Vertical
- Target Audience Age
- Income Bracket
- Impressions
- Clicks
- Conversions
- Ad Spend
- Revenue
- Profit
- CTR
- CPC
- Conversion Rate
- ROAS
etc

## Data Cleaning

The dataset was cleaned using Power Query.

### Cleaning Steps

- Imported dataset into Power BI.
- Verified and corrected data types.
- Removed duplicate records.
- Cleaned text columns.
- Checked missing values.
- Validated numeric columns.
- Retained negative profit values because they represent campaign losses.
- Loaded the cleaned dataset into Power BI.

## Key Business Insights

- The highest-performing campaign objective generated approximately **110M** in revenue.
- Google Ads delivered the highest profit (**80M**) and the highest average conversion rate.
- Facebook ranked second in platform profitability.
- Customer response varied across different target audience age groups.
- Finance generated the highest revenue among all industry verticals.
- Higher advertising spend generally resulted in higher revenue, although campaign efficiency varied.

---

## Business Recommendations

- Increase investment in the highest-performing campaign objectives.
- Allocate more budget to high-performing marketing platforms.
- Focus on customer segments with stronger engagement.
- Optimize advertising spending for improved ROI.
- Monitor campaign performance continuously using interactive dashboards.
